EXPERT BYOK MODE Gemini API key

Never saved or logged. It is sent in an x-goog-api-key header directly to generativelanguage.googleapis.com. Google advises against browser-side production keys; use a restricted, disposable key. This tab forgets it after each run.

Why not Gemma 4 or Qwen3-TTS here?

The working 31B/1.7B native pipeline is too large for reliable browser execution. This lab uses browser-tested variants and does not pretend otherwise.
