How it works

Six automated stages

One command runs everything below. Only two stages call paid APIs — together they cost under ₹10 for a 7-minute lecture.

1

Download

yt-dlp fetches any YouTube URL; local files work too. No channel ownership or allowlist.

2

Find where speech starts

ffmpeg detects the intro music so the dub begins at the first spoken word — the original opening is kept.

3

Transcribe on-device

MLX Whisper runs locally on Apple Silicon and produces time-stamped English segments. Free, and the audio stays on your machine.

4

Translate for speaking

Gemini 2.5 Flash writes conversational Hindi sized to fit each time slot — with technical terms deliberately left in English.

5

Give it a voice

Sarvam AI (7 native Indian voices), Gemini TTS, or free Edge TTS — synthesized in parallel and cached per segment.

6

Rebuild the video

Each clip is gently speed-matched to its slot (0.95–1.35×, never truncated — long sentences borrow from the following pause), the original soundtrack plays during pauses, and ffmpeg stitches it all back — plus a Hindi .srt.

Try it yourself

One command to dub a lecture

Needs Python 3.11+, ffmpeg, and a GEMINI_API_KEY — add a SARVAM_API_KEY for the native Indian voices (₹1,000 free credits on signup covers roughly 10 hours of lectures).

terminal
# install git clone https://github.com/nipunbatra/vidvaani.git cd vidvaani && uv sync # quick taste — dubs the first 5 segments only uv run vidvaani dub "https://youtube.com/watch?v=VIDEO_ID" # full lecture, native Indian voice, plus subtitles uv run vidvaani dub "https://youtube.com/watch?v=VIDEO_ID" --full -b sarvam -v abhilash # professional browser control room with live phase inspection uv run --frozen vidvaani-web
Fair questions

FAQ

Doesn't YouTube dub videos automatically now?

YouTube decides which eligible creators receive access, and rollout is gradual. Nipun's established lecture channel is still not enabled, despite its substantial catalogue. When access is available, generated dubs cannot be edited, and there is no direct control over voice or technical terminology. VidVaani can process a permitted source without waiting for channel eligibility.

Why not just use Sarvam's own dubbing product?

Sarvam Studio produces formal, fully-translated Hindi — "area" becomes क्षेत्रफल, "gradient" becomes प्रवणता. STEM students used to Hinglish find that foreign. VidVaani uses the same Sarvam voices through the API, but controls the register: technical terms stay in English. The Dashboard card in the voice gallery shows the difference directly.

Is the translation perfect?

No — it's a strong first draft. For teaching use we recommend a quick faculty pass over the generated Hindi .srt file; edits are one re-assembly away, and the transcript is cached so nothing else re-runs. A human-review workflow is on the roadmap.

What do I need to run it?

A Mac with Apple Silicon (for local Whisper transcription), ffmpeg, and free-tier API keys. With Edge TTS the total cost is just the translation — about ₹12 per lecture-hour.

Can it run fully offline?

Yes — experimentally. Transcription is already local; swap Gemini for Gemma 4 and Sarvam for Qwen3-TTS (both via MLX) and the whole pipeline runs on a Mac at ₹0. The "Fully local" card used Gemma 4 12B + the default Qwen voice; the "Your own voice" card upgrades to Gemma 4 31B and clones the lecturer from 28 s of his English — measured July 2026: translation 59 s, cloned speech 1.6× real-time, ~3 min end-to-end for the 58 s clip. Voice cloning was climbed as a ladder in one day: single reference take 0.76 → best-of-16 scored search 0.85 → 7-minute laptop LoRA on 30 min of his speech 0.86 → full SFT on a lab A100 with a 175-minute speaker-verified dataset (18 videos checked, 1,777 utterances gated) → published dub 0.89, vs 0.93 for his real voice against itself and ~0.3 for other voices. Every published take passes an STT content check — it caught fine-tuned takes that sounded exactly like him while saying the wrong words. Cloned voices are published only with the speaker's consent.

Only Hindi?

Hindi today. The Sarvam voices cover 11 Indian languages and the translation prompt is a parameter, so Gujarati, Tamil, or Bengali are natural next steps.

How does it stay in sync with the slides?

The translator gets a word budget for each time slot, so the Hindi is written to fit before any audio exists. The audio is then gently speed-matched (at most ~35% faster, never noticeably slower) and long sentences borrow from the following pause rather than being cut. Pauses keep the original soundtrack, so the classroom feel survives.
